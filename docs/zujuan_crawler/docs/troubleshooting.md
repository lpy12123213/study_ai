# 故障排查：非目标响应类型与判别特征（访客态）

更新时间：2026-02-08

本文档集以“访客态”（不登录）为前提。故障排查的核心在于区分：
- 目标响应：预期的 JSON（列表接口）或业务 HTML（详情页）
- 非目标响应：挑战页/登录页/占位文本等（不包含目标数据）

本章给出常见非目标响应的可观察特征与含义解释。

范围边界：
- 本章不包含挑战页绕过、验证码绕过、登录绕过或付费内容绕过。

---

## 1) HTTP 状态码正常但内容异常

### 1.1 登录页 HTML

可观察特征：
- HTTP `200 OK`
- `Content-Type: text/html`
- HTML 中包含登录相关资源或提示（例如 `login.css`、`login-popup.css`、“登录”提示文案）

含义解释：
- 该端点或该内容需要登录/授权；访客态无法获得结构化数据。

### 1.2 302 跳转到登录页

可观察特征：
- HTTP `302 Found`
- 响应头包含 `Location: https://zujuan.xkw.com/login?ReturnUrl=...`

含义解释：
- 服务端以重定向方式引导到登录页；访客态无法获得目标数据。

### 1.3 挑战页（JS Challenge / 风控页）

可观察特征（命中任意一项即可判为挑战页）：
- `Content-Type: text/html`，且 HTML 顶部出现 `<body onload="check()">`
- HTML 中出现 `alicfw_gfver`
- `<head>` 中出现 `aliyun_waf_aa` / `aliyun_waf_bb`
- HTML 中出现 `acw_sc__v2`

含义解释：
- 该响应为风控/挑战页面，不包含目标业务内容。本文档范围不包含绕过实现。

### 1.4 短文本占位（示例：`welcome to imworld`）

可观察特征：
- HTTP `200 OK`
- 响应体非常短（例如几十字节）
- 在请求 `/zujuan-api/base` 等端点时出现与业务无关的纯文本

含义解释（抽样观测）：
- 该现象与请求头（尤其是 `User-Agent`）形态相关；当 UA 过于“脚本化”时更易出现。
- 该响应不包含目标枚举数据。

`/zujuan-api/base` 的请求头敏感性与解析方式见：`docs/api/base.md`。

## 2) 常见状态码/错误码与语义

| 现象 | 可观察表现 | 含义解释（访客态语境） |
|---|---|---|
| `401 Unauthorized` | 状态码 401 | 端点需要登录/授权 |
| `403`（JSON 文案含“请求未授权”） | 状态码 403 或 JSON 提示 | 端点受控或需要授权（例如部分搜索/切换题库接口） |
| `302`（Location 指向 `/login`） | 302 + Location | 端点需要登录 |
| `405 Method Not Allowed` | 状态码 405 | 请求方法不匹配（GET/POST），或端点在访客态不开放 |
| JSON `code=500` 且文案含“系统异常” | JSON 错误 | 参数不合法、节点不存在、或服务端异常（需结合请求参数排查） |
| `404` | 状态码 404 | 路径不存在、大小写路径不匹配（sitemap 常见），或请求上下文缺失导致路由不可达 |

## 3) 判别非目标响应的最小信息集

对每个请求，以下信息足以支持大多数“是否拿到目标数据”的判别：
- HTTP 状态码
- `Content-Type`
- 响应体前若干字符（例如前 200 字符）

挑战页/登录页的判别特征见：
- `docs/02-session-cookies-headers.md`
- `docs/13-stability-profile.md`
