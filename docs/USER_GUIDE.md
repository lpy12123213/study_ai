# 使用指南

本文面向 Study AI 的最终使用者，说明主要页面、工作流、输入要求和使用边界。开发、部署和 API 细节分别见 `DEVELOPMENT.md`、`DEPLOYMENT.md` 和 `API.md`。

## 使用边界

- AI 生成内容必须人工复核后用于教学、出题或发布。
- 题源抓取应遵守目标站点条款和合理频率。
- 分享链接不应包含密钥、内部资料、学生隐私或未授权题目内容。
- 试卷与题库默认以元数据为主，题干、答案和解析的持久化由配置控制。

## 功能总览

| 页面 | 用途 | 主要产物 |
| --- | --- | --- |
| 对话 | 工具编排、题目检索、试卷创建 | 对话记录、试卷 |
| 蓝图组卷 | 按结构化约束组卷 | 题目 ID 列表、试卷 |
| 自学资料 | 生成主题学习材料 | 学习资料、LaTeX 草稿 |
| 教案 | 生成教学设计 | 教案、导出文件 |
| DeepThink | 多路径解题 | 解题过程 |
| 本地题库 | 管理抓取题和 AI 生成题 | 题库条目 |
| AI 出题 | 生成并审核题目草稿 | preview/session、题库条目 |
| 试卷管理 | 查看、导出、删除试卷 | Markdown/LaTeX/PDF/DOCX |
| 任务中心 | 追踪长任务 | 任务状态、事件 |

旧版入口会自动跳转到新入口：`/blueprint` → `/compose`、`/study-materials` → `/materials`、`/question-library` → `/library`、`/ai-generate` → `/library?tab=generate`，旧书签无需修改。

## 登录

启动后进入前端页面，使用 `.env` 中的管理员账号登录：

- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`

开发环境可以使用示例值；生产或共享环境必须更换密码和 `JWT_SECRET`。

## 对话

入口：`/chat`

适用场景：

- 让 AI 根据需求检索题目。
- 让 AI 创建试卷。
- 基于已有对话继续追问。
- 分叉对话，保留不同方案。

输入要求：

- 明确学科、年级、题型、难度、数量。
- 需要创建试卷时，给出试卷名称。
- 题源结果不稳定时，缩小主题或加上教材、年级条件。

## 蓝图组卷

入口：`/compose`（蓝图 标签页；旧 `/blueprint` 自动跳转）

适用于按结构化规则组卷，例如：

- 选择题 10 道，函数专题，中等难度。
- 填空题 5 道，指数函数，简单到中等。
- 解答题 3 道，综合应用，中等偏难。

操作流程：

1. 先选择学科和筛选条件。
2. 分槽位配置题型、知识点、难度和数量。
3. 开启题干去重和质量阈值。
4. 检查预览后保存试卷。

筛选字段说明见 `SEARCH_FILTERS_AND_BLUEPRINTS.md`。

## 自学资料

入口：`/materials`（旧 `/study-materials` 自动跳转）

适用场景：

- 为一个主题生成系统讲解。
- 生成可继续改进的学习资料。
- 将资料转换为 LaTeX 或导出。

输入要求：

- 主题应保持明确；例如使用“导数与函数单调性”，避免只输入“数学”。
- 对大主题选择 `deep` 或 `research` 预设。
- 生成过程中刷新页面后，任务会通过事件序号续流。
- 结果不够深入时，用继续任务做“补充例题”“加深证明”“重新组织结构”等改进。

## 教案

规划中：后端 API 已完整，前端页面尚未上线。

适用场景：

- 生成教学目标、重难点、课堂流程、板书和练习。

## DeepThink

入口：`/deepthink`

适用于复杂题目和需要多路径推理的问题。

输入要求：

- 输入完整题干。
- 如果题目依赖图片，尽量补充文字描述。
- 对“只要答案”或“需要完整过程”提前说明。

## 本地题库

入口：`/library`（旧 `/question-library` 自动跳转）

功能：

- 浏览本地题库。
- 按学科、来源、隐藏状态、评分、关键词筛选。
- 查看详情。
- 收藏、隐藏、取消隐藏。
- 批量删除。
- 导出到题篮。

使用要求：

- 抓取题目后先用评分和预览做清洗。
- 低质量题优先隐藏；只有确认无需保留时再删除。
- 批量删除前确认筛选条件和选中数量。

## AI 出题

入口：`/library?tab=generate`（旧 `/ai-generate` 自动跳转）

流程：

1. 输入学科、主题、题型、难度和数量。
2. 可选择参考本地资料或参考题。
3. 等待任务生成草稿。
4. 审核题目，必要时重写或调整。
5. 确认后写入本地题库。

原则：

- AI 草稿在确认前不是正式题库条目。
- 生成结果应人工检查答案、解析和题目条件。
- 复杂题型宜采用少量、多轮生成方式，并逐轮审核。

## 试卷管理

入口：`/papers`

功能：

- 查看试卷列表。
- 查看试卷详情。
- 获取题目链接。
- 导出 Markdown、LaTeX、PDF 或 DOCX。
- 删除试卷。

导出要求：

- 先导出 Markdown 或 LaTeX 检查内容。
- PDF 依赖本机 LaTeX。
- DOCX 推荐安装 Pandoc。

## 任务中心

入口：`/tasks`

功能：

- 查看长任务列表。
- 查看任务状态、进度、事件。
- 对支持的任务执行暂停、取消、重试。

长任务包括：

- 自学资料。
- 教案。
- DeepThink。
- AI 出题。
- 题库抓取和评分。
- 试卷生成和导出。
- 知识视频。

## 设置

入口：`/settings`

用于管理用户偏好、界面设置和部分导入导出能力。系统级模型、模型供应商和模型 API Key 统一以 `config/model.json` 为准；`.env` 只保存非模型运行配置和外部搜索服务密钥。

## 分享

入口：`/share/:token`

分享页用于访问被分享的公开内容。包含敏感信息、个人信息或未授权内容的资料不得生成公开分享链接。
